# 📦 Sistema de Control de Inventario (CLI)

Aplicación en Python orientada a objetos para la gestión de productos, entradas, salidas y control de stock en tiempo real.

## 🚀 Características
- **Gestión de Stock:** Altas, reposición y retiro de unidades con validación de disponibilidad.
- **Arquitectura POO:** Clases modulares (`Producto`, `Inventario`) con búsqueda optimizada $O(1)$.
- **Exportación de Reportes:** Generación automática de archivos en formatos `.csv` y `.xlsx` (Excel estilizado con fórmulas).
- **Interfaz Interactiva:** Menú en terminal validado contra entradas incorrectas.

## 🛠️ Tecnologías
- Python 3.10+
- [openpyxl](https://openpyxl.readthedocs.io/) (para reportes en Excel)
